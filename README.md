# TP-combat-Personnages

Projet de simulation de combat entre personnages (Guerrier, Mage, Archer) en TypeScript.

## Prérequis

- [Node.js](https://nodejs.org/) installé sur votre machine.

## Installation

```bash
npm install
```

## Lancer le projet

```bash
npm run dev
```

## Fonctionnement

Le projet simule un combat tour par tour. L'initiative est déterminée par la vitesse d'attaque des personnages. À chaque tour, ils peuvent soit attaquer, soit se défendre (bloquer les dégâts du prochain tour).
